## Deploy no Vercel

### 1. Suba para o GitHub
Arraste os arquivos em: github.com → seu repositório → "carregando um arquivo existente"

### 2. Importe no Vercel
- vercel.com → "Add New Project" → seleciona o repositório → Deploy

### 3. Variáveis de ambiente
No Vercel: **Settings → Environment Variables**

| Nome | Onde pegar |
|------|-----------|
| `OPENAI_API_KEY` | platform.openai.com/api-keys |
| `SUPABASE_URL` | `https://zmblknnfoqpvapdymjwn.supabase.co` |
| `SUPABASE_PUBLISHABLE_KEY` | Chave anon do Supabase |
| `ADMIN_PASSWORD` | Inventa uma senha |
